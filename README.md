# XAHIL - AI Trading Agent (paper only)

A Claude Code swing-trading agent on an **Alpaca paper account with $100,000 of virtual money**,
adapted from Nate Herk's "Opus 4.7 Trading Bot - Setup Guide". **Claude is the decision-maker**
(research, catalysts, thesis judgement, reviews). **Python (`python -m xahil`) is the deterministic
layer**: paper-only broker access, risk engine, protection, reconciliation, analysis, memory and
run safety.

- **Status:** Phase 4 cloud dry-run prepared ($100,000 baseline). Order execution is **off** (dry-run). No scheduled tasks are active.
- **Start here:** [docs/SETUP.md](docs/SETUP.md) · Latest: [docs/PHASE4-READINESS.md](docs/PHASE4-READINESS.md) · Deploy: [docs/CLOUD-DEPLOYMENT.md](docs/CLOUD-DEPLOYMENT.md)
- **Why it differs from the guide:** [docs/AUDIT.md](docs/AUDIT.md), [docs/GUIDE-CONFORMANCE.md](docs/GUIDE-CONFORMANCE.md)

## How a run works
```
scheduled task (CRON_TZ=America/New_York)
  └─ run-claim: sync memory from claude/xahil-state → holiday/window/duplicate check → push + verify claim
  └─ preflight → reconcile (Alpaca = truth; resets, gaps, unresolved orders)
  └─ Claude: research (+evidence), regime & signals (advisory), decisions, logs
  └─ python3 -m xahil buy/sell/protect → risk engine → re-check → dry-run proposal (or order, once approved)
  └─ run-finish → guard → persist (memory/ only, to claude/xahil-state, never main, never force) → Telegram
```

| Workflow | ET | Does |
|---|---|---|
| pre-market | 08:07 Mon–Fri | regime, signals, cited research, ideas, decision log |
| market-open | 09:47 Mon–Fri | GTC protection first, then whole-share buys (dry-run) |
| midday | 12:07 Mon–Fri | −7% risk exits, stop tightening, thesis exits |
| daily-summary | 16:22 Mon–Fri | snapshot, P&L/drawdown vs SPY, overnight-protection status |
| weekly-review | Sat 10:07 | weekly stats, learning analysis, monthly backtest, strategy proposals |

## Hard limits (in code)
Paper endpoint only · cash only · long only · US-listed stocks/plain ETFs · no options, futures,
crypto, leveraged/inverse/derivative ETPs or shorts · 5% per position · 20% total · 3 buys/week ·
4 positions · **whole shares only, each with a GTC stop** (a DAY stop is never overnight protection) ·
fresh quotes · market open · day-trade info known · no discretionary same-day round trips.

## Layout
```
xahil/      risk, alpaca, cli, cli_intel, ta, signals, regime, backtest, learning, runs, persist,
            reconcile, journal, metrics, notify, research, data, integrations, guard, config
config/     risk limits, execution switch, strategy params, signal params (advisory), universe (proposed)
routines/   5 cloud prompts generated by _build.py + README (schedule, environment, activation)
memory/     logs, reviews, proposals, mistakes, backtests/, state/ (journals, snapshots, run markers)
tests/      234 offline tests (fake Alpaca, synthetic bars, temporary Git repos)
docs/       AUDIT, GUIDE-CONFORMANCE, SETUP, PHASE2-ACCEPTANCE, PHASE3-ACCEPTANCE
```
